# Atelier CréerSon

Site vitrine et studio de personnalisation textile (t-shirts, sweats, tote bags, broderie et impression).

## Lancer en local

```
pnpm install
pnpm dev
```

Puis ouvrir http://localhost:3005

## Réglages

Tout se règle dans `js/config.js` : email, réception des demandes, réseaux, prix, techniques.
